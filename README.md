# Painel_Ciru_OCI

Painel interno em **Shiny** para monitoramento da produção de **Cirurgias Eletivas** e **Ofertas de Cuidados Integrados (OCI)**.

## Objetivos

- Monitorar a produção mensal de cirurgias eletivas e OCI;
- Acompanhar indicadores por UF, município e estabelecimento;
- Disponibilizar visualizações interativas para apoio ao monitoramento do Programa Agora Tem Especialistas;


## Tecnologias

- R
- Shiny
- tidyverse
- plotly
- DT
- echarts4r
- bslib
